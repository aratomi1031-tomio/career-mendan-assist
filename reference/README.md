# 参考資料（CC/CL発言の1分刻み整理用）

career-mendan-assist アプリ自体は音声の文字起こし・話者識別を行いません（外部にデータを送信しない設計方針のため）。
このフォルダは、別途取得した文字起こしテキストをAIで整理する際に使う参考資料です。

## 使い方

1. 何らかの方法（ローカルの音声認識ソフトなど）で、面談録音を文字起こしする。
2. `CC-CL整理プロンプト.txt` の内容をコピーし、末尾の「【文字起こしテキスト】」の下に文字起こし本文を貼り付けて、Claude等のAIに渡す。
3. AIが出力したMarkdown表を、`面談記録_整理用サンプル.docx` の書式（経過時間・話者・発言内容の表）に貼り替えて保存する。

## ファイル一覧

- `CC-CL整理プロンプト.txt` — AIに渡すプロンプト本文。
- `面談記録_整理用サンプル.docx` — 出力先として使うWordの書式サンプル（面談基本情報＋発言記録の表＋発言配分の概観、の3セクション構成）。
