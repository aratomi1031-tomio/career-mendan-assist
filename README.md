# キャリア面談アシスト

キャリア面談（カウンセリング）を行う際に、タイマー・録音・フェーズごとの共通スキルチェック・面談後の結果確認を支援するアプリです。

**すべてのデータは利用者自身のブラウザ内にのみ保存され、外部（インターネット）には一切送信されません。** 録音・記録のいずれも、クラウドAPIやAI連携を使わない仕組みで動いています。

---

## 公開URLで使う場合(他の人にも使ってもらう)

このアプリはGitHub Pagesで公開できます。公開URL(例: `https://aratomi1031-tomio.github.io/career-mendan-assist/`)を開いた人は、それぞれ自分のブラウザの中だけにデータが保存されます。

- 利用者ごとにデータは完全に分かれており、他の利用者や公開者(あなた)からも見えません・共有されません。
- サーバー側には何もデータが送られず、記録されません。ソースコードが公開されているだけで、面談データを預かる仕組みではありません。
- HTTPSで配信されるため、ローカルサーバー(`start.bat`)を使わなくても録音機能がそのまま動作します。
- ブラウザのデータ(IndexedDB)は「その端末・そのブラウザだけ」に保存されるため、複数の端末間でデータを引き継ぐことはできません。別の端末でも使う場合は、設定画面の「全データをバックアップ(JSON)」でエクスポートし、別端末で「バックアップから復元」してください。

## ローカルで使う場合（このPC内で完結させたい場合の起動方法）

1. `start.bat` をダブルクリックしてください。
2. 黒いウィンドウ（コンソール）が開き、`サーバー起動しました: http://localhost:8420/` のように表示されます。
3. 既定のブラウザが自動的に開き、アプリが表示されます。
4. 使い終わったら、コンソールのウィンドウで **Ctrl+C** を押すとサーバーが停止します（ブラウザのタブを閉じるだけでは、次回起動時の妨げにはなりません）。

> **重要**: `docs\index.html` を直接ダブルクリックしないでください。マイク（録音）機能が正しく動作しません。必ず `start.bat` からブラウザ経由で開いてください。

### 初回だけ確認すること
- Windowsファイアウォールの許可ダイアログが出た場合は「許可」してください（外部からのアクセスではなく、このPC内での通信のためのものです）。
- ブラウザでマイクの利用許可を聞かれたら、録音を使う場合は「許可」してください。

## 録音データの保存場所について（重要）

**録音ファイルを保存するときは、OneDriveなどクラウド同期対象外のフォルダを選んでください。**（このアプリの開発元フォルダはOneDrive配下の「デスクトップ」にありますが、これは保存先には使わないでください。）

例：`C:\CareerMendanRecordings\` のような、クラウド同期の対象外の専用フォルダを最初に1つ作っておくことをおすすめします。

これを怠ると、面談の録音（相談者の個人情報を含む可能性があるもの）が自動的にクラウドにアップロードされてしまい、「外部に一切送信しない」という設計方針が保存操作ひとつで崩れてしまいます。保存ダイアログが出たら、保存先フォルダに注意してください。この注意点は、公開URL経由で使う場合も同様です。

---

## 基本的な使い方

1. **面談準備画面**で、相談者からの同意（録音・記録について）を確認してチェックを入れ、「面談を開始する」を押します。
2. **面談中画面**では、
   - 全体タイマーとフェーズごとのタイマーが自動で進みます。
   - フェーズボタンをクリックして、現在の進行フェーズ（関係構築→問題の把握→目標設定→方策の実行→結果の評価、など）を手動で切り替えます。
   - 現在のフェーズに応じた「共通スキルチェック」項目をクリックすると、そのタイミングが記録されます（会話を止めずにワンクリックで完結）。
   - 気づいたことは「メモ」欄にその場で一言残せます。
   - 録音は面談開始と同時に自動的に始まります（マイクが使えない場合は録音なしで続行します）。
   - 「面談を終了する」を押すと録音が自動的に停止し、保存先を選ぶダイアログが表示されます。
3. **面談サマリー画面**は「面談結果概要」「逐語プロンプト（参考）」の2タブ構成です。「面談結果概要」タブでは、フェーズ別の時間配分・チェックリスト実施状況・メモが表示され、.txtファイルとしてダウンロードできます。「逐語プロンプト（参考）」タブでは、別途取得した文字起こしをAIに渡してCC/CL発言を1分刻みで整理してもらうためのプロンプトを確認・保存できます（音声の文字起こし自体はこのアプリの外で行う必要があります）。
4. **履歴画面**で、過去のセッションを振り返ったり、削除したりできます。
5. **設定画面**で、フェーズの構成（名称・目標時間・順番）やチェックリストの項目を自由に編集できます。初期値はあくまで叩き台です。ご自身の手法・所属組織の基準に合わせて書き換えてください。

---

## データのバックアップ

設定画面の「全データをバックアップ（JSON）」で、すべてのセッション記録・設定をファイルに書き出せます。ブラウザの保存領域が万が一クリアされた場合に備えて、定期的にバックアップを取ることをおすすめします。「バックアップから復元」で元に戻せます。

---

## できないこと（設計上の割り切り）

- **音声の文字起こし・話者分離はありません。** ブラウザの音声認識機能や外部AIサービスはGoogleなどの外部サーバーに音声を送信する仕組みのため、「外部に送信しない」という方針と両立できず、あえて実装していません。文字起こしが必要な場合は別途アプリの外で行い、「逐語プロンプト（参考）」タブのプロンプトと組み合わせてAIに整理してもらってください。
- **面談結果概要はAIによる自然文要約ではありません。** 記録した時間・チェック内容・メモをそのまま整理して表示・保存しているだけです。
- 録音の一時停止・再開はできません（一連の面談で開始・停止は1回ずつ）。中断が必要な場合は、面談を一度終了し、新しいセッションとして再開してください。

## トラブルシューティング

- **サーバーが起動しない（`AccessDenied`エラーが出る）**: まれに、組織のセキュリティポリシーでポートのバインドが制限されている場合があります。PowerShellを管理者権限で開き、次のコマンドを一度だけ実行してから、通常どおり`start.bat`を使ってください。
  ```
  netsh http add urlacl url=http://localhost:8420/ user=%USERNAME%
  ```
- **ポート8420が使用中**: 自動的に8421, 8422...と次のポートが試されます。表示されたURLを確認してください。
- **マイクの許可が出ない/録音できない**: 必ず`start.bat`経由で開いた`http://localhost:...`のページであることを確認してください（`file://`から開いた場合は動作しません）。
